System Architecture

How a plain-English request travels through the system. The language model works only at the two ends (understanding and writing). Everything in the middle runs as fixed, dependable steps, and the whole system stays on local hardware.

Component notes

Smart edge · in

Intent extraction

The only place the model decides anything. A single constrained call, so it rarely goes wrong.

Deterministic core

Router

Plain Python maps the intent to a function. No model here means no compounding errors.

Tool layer

Retrieval, database, model

Exposed through FastMCP. Each does one job and returns data, not decisions.

Smart edge · out

Response generation

Turns retrieved data into readable text. Just summarising, which the local model handles easily.

Safety

Human-confirmed writes

Any change to a record is shown to staff to approve before it is saved.

Trust

Evaluation harness

Scores the model steps against known-correct answers so accuracy is measured, not assumed.
